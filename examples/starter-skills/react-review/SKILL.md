# React review

Review a React interface from the user's perspective and the component boundary.

1. Trace rendering, state, effects, event handling, and loading or error states.
2. Check keyboard access, labels, focus behavior, semantics, and readable contrast.
3. Look for unnecessary work, unstable keys, stale closures, and avoidable re-renders.
4. Verify responsive behavior and resilient empty or slow data states.
5. Report concrete findings with a suggested fix and a focused test or inspection.
6. Preserve existing design language unless the request explicitly changes it.
